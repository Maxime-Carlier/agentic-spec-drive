# Tags

Tags allowed in spec frontmatter. Add one here before using it.

Area (rename or extend for your project):
- `app`: the main application
- `workflow`: specs, skills, agents and tooling of the repository

Kind:
- `feature`: new behaviour
- `fix`: bug fix
- `chore`: maintenance with no visible change
- `design`: visual or UX work
- `perf`: performance work
- `content`: text or data changes
